# 统一网关 & 业务接口规范文档 (v1.0.0)

本文档用于定义系统内普通业务接口与统一网关指令接口的请求与响应规范。所有接口数据传输默认采用 `UTF-8` 编码。

---

## 一、 全局通用说明

### 1. 环境地址 (Base URL)
* **测试环境 (Test):** `http://localhost:3000`
* **网关地址 (Gateway):** `http://localhost:3000/tars/v1/gateway`

### 2. 全局通用请求头 (Headers)
| 参数名 | 是否必填 | 示例值 | 参数描述 |
| :--- | :--- | :--- | :--- |
| **Content-Type** | 是 | `application/json` | 统一数据传输格式（除上传文件外） |
| **User-Agent** | 否 | `Apifox/1.0.0 (https://apifox.com)` | 客户端标识 |
| **Connection** | 否 | `keep-alive` | 保持长连接 |

### 3. 全局鉴权机制
系统采用 **Cookie 保持机制** 进行用户登录态管理：
1. 调用“用户名密码登录”或“手机号验证码登录”接口成功后，后端会在响应头中返回 `Set-Cookie`。
2. 客户端需截取并保存凭证（格式如：`session=716722b0-xxxx-xxxx-xxxx-8cc844e236c0`）。
3. **后续所有需要登录态的业务接口及网关指令，必须在请求头中携带 `Cookie: session=xxxx`，否则系统将拦截并返回 HTTP 401 状态码。**

### 4. 全局公共业务状态码 (Code)
> 注意：业务状态码返回于 JSON 响应体中，与标准 HTTP 状态码（200, 401, 500等）相互独立。

| 业务状态码 (code) | 含义描述 | 触发场景 / 建议处理方案 |
| :--- | :--- | :--- |
| **0** | `Success` | 请求成功且业务逻辑处理正常 |
| **40001** | `Unauthorized` | 未登录或登录态（Cookie）已过期，客户端应重定向至登录页 |
| **40003** | `Permission Denied` | 权限不足，禁止访问该资源 |
| **50000** | `Internal Error` | 服务器内部未知异常，请联系系统管理员 |

## 二、 账户与登录模块接口

### 1. 用户名密码登录
* **接口名称：** 用户名密码登录
* **请求路由：** `POST` `/login_by_username`
* **接口描述：** 用于后台管理人员或常规账号通过账密换取 Session 登录凭证。

#### 请求参数 (Body)
| 参数名 | 类型 | 是否必填 | 约束/限制条件 | 示例值 | 参数描述 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **username** | String | **是** | 4-20位字符，由字母或数字组成 | `admin` | 登录账号 |
| **password** | String | **是** | 长度不少于6位 | `admin123` | 账号密码 |
| **returnToken** | Boolean | 否 | 默认 `false` | `false` | 是否同时返回 Bearer Token |

#### 响应体 (Response Body)
| 字段名 | 类型 | 含义描述 | 备注 |
| :--- | :--- | :--- | :--- |
| **code** | Integer | 业务状态码 | `0` 代表成功 |
| **msg** | String | 提示信息 | `success` 或错误描述 |
| **data** | Object | 业务核心数据 | 成功时返回，失败为 `null` |
| └─ **userId** | String | 用户唯一标识 | 32位 UUID |

#### 成功响应示例 (HTTP 200)
> **注意：** 此时响应头中会携带 `Set-Cookie: session=716722b0-3e8a-49ff-aaa5-8cc844e236c0; Path=/; HttpOnly`
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "userId": "u_9527_716722b0aaa5"
  }
}
```



## 三、 统一网关指令模块接口 (Gateway)

### 1. 查询患者信息 (指令 16001)

- **接口名称：** 查询患者信息
- **请求路由：** `POST` `/tars/v1/gateway`
- **依赖关系：** **强依赖登录态**。调用前必须保证已成功登录，且通过 Header 传入有效 Cookie。
- **接口幂等性：** 具备幂等性（重复调用不会改变服务器状态，仅用于数据查询）。

#### 请求头 (Request Headers)

| 参数名      | 类型   | 是否必填 | 示例值                                         | 参数描述                             |
| ----------- | ------ | -------- | ---------------------------------------------- | ------------------------------------ |
| **command** | String | **是**   | `16001`                                        | **网关核心路由指令号**，固定为 16001 |
| **Cookie**  | String | **是**   | `session=716722b0-3e8a-49ff-aaa5-8cc844e236c0` | 登录态会话凭证                       |

#### 请求体 (Request Body)

> 本接口无请求体参数，发送请求时传空对象 `{}` 即可。

#### 响应体 (Response Body)

| 字段名           | 类型    | 含义描述           | 约束与取值说明              |
| ---------------- | ------- | ------------------ | --------------------------- |
| **code**         | Integer | 业务状态码         | `0` 成功，其他参见全局说明  |
| **msg**          | String  | 提示信息           | 失败时的具体原因描述        |
| **data**         | Object  | 患者核心信息数据块 | 鉴权失败或无数据时为 `null` |
| └─ **patientId** | String  | 患者唯一ID         | 32位 字符串                 |
| └─ **name**      | String  | 患者姓名           | 脱敏展示，形如“张*三”       |
| └─ **gender**    | Integer | 患者性别           | `1`: 男, `2`: 女, `0`: 未知 |
| └─ **age**       | Integer | 患者年龄           | 取值范围：`1 ~ 120`         |

#### 成功响应示例 (HTTP 200)

JSON

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "patientId": "p_2026_0624_8cc844",
    "name": "张*三",
    "gender": 1,
    "age": 28
  }
}
```

#### 失败响应示例 (HTTP 401 - 未登录或凭证过期)

JSON

```json
{
  "code": 40001,
  "msg": "用户登录态已失效，请重新登录",
  "data": null
}
```

#### 失败响应示例 (HTTP 200 - 业务异常 / 指令未定义)

JSON

```json
{
  "code": 50002,
  "msg": "网关无此路由指令，请检查 command 传参是否正确",
  "data": null
}
```
